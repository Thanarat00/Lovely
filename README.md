# A Letter for You: The Sunflower Sky

เว็บของขวัญแบบเลื่อนดูทีละฉาก สำหรับคนที่ชอบดอกทานตะวันกับท้องฟ้าสีรุ้ง เขียนด้วย React ไม่ได้เป็นหน้า HTML เปล่า

## รันในเครื่อง

ต้องมี Node.js 20 ขึ้นไป

```bash
npm install
npm run dev
```

เปิด http://127.0.0.1:5173

ตรวจลอจิกความคืบหน้า:

```bash
npm test
```

สร้างไฟล์สำหรับขึ้นโฮสต์:

```bash
npm run build
npm run preview
```

ไฟล์ที่พร้อมอัปโหลดอยู่ในโฟลเดอร์ `dist`

## โครงโปรเจกต์

- `src/App.jsx` เปิดฉากตามลำดับที่ปลดล็อก
- `src/components/scenes/` เจ็ดฉาก
- `src/content/copy.js` ข้อความภาษาไทยทั้งหมด รวมจดหมาย
- `src/lib/progress.js` กติกาเกมและบันทึกความคืบหน้า
- `src/hooks/useStoryMotion.js` GSAP ScrollTrigger พาเมฆตามการเลื่อน และจำว่าอยู่ฉากไหน
- `src/components/ParticleField.jsx` กลีบดอก ประกาย และดาวตกบน canvas
- เสียงบรรยากาศสร้างจาก Web Audio ไม่ได้พึ่งไฟล์เสียงภายนอก
- ภาพทั้งหมดเป็น SVG และ CSS จึงไม่มีไฟล์รูปที่โหลดไม่เจอ

## สิ่งที่ผู้รับทำได้

1. ท้องฟ้าเช้า แล้วเข้าสวน
2. หยอดเมล็ด ให้แสง รดน้ำ แล้วดูดอกบาน
3. เก็บดาวห้าดวง แต่ละดวงมีคำให้กำลังใจ
4. แตะสีรุ้งห้าแถบ
5. เลือกความรู้สึกวันนี้
6. เปิดซองจดหมายตราดอกทานตะวัน อ่านแล้วพับกลับได้
7. ช่อทานตะวันกับกล่องของขวัญ ดูซ้ำได้

ความคืบหน้าอยู่ใน `localStorage` คีย์ `sunflower-sky-v1` ปุ่มตั้งค่ามุมขวาบนมี "ดูตั้งแต่ต้น" และ "ล้างความคืบหน้า" เสียงปิดไว้จนผู้รับกดเปิดเอง

ทางลัดที่ซ่อนไว้: แตะพระอาทิตย์ห้าครั้ง แตะผีเสื้อ หรือแตะก้อนหินในสวนสามครั้ง

## การเคลื่อนไหว

แต่ละฉากสูงเท่าหน้าจอและเลื่อนแบบ snap เมฆขยับตามสกรอลล์ผ่าน ScrollTrigger ฝาซองหมุนด้วย GSAP แบบ 3D หัวดอกตอนบานใช้ GSAP ส่วนกลีบที่ร่วงและประกายอยู่บน canvas ด้วย `requestAnimationFrame` ถ้าเครื่องตั้ง reduced motion แอนิเมชันวนจะหยุด และเกมยังกดจบได้

## แก้จดหมาย

เปิด `src/content/copy.js` แล้วแก้ `letter.paragraphs` บรรทัดที่มี `\n` คือการขึ้นบรรทัดใหม่ในกระดาษ คำในฉากอื่นก็อยู่ในไฟล์เดียวกัน

## ขึ้นโฮสต์

`vite.config.js` ตั้ง `base: './'` แล้ว จึงอัปโหลด `dist` ได้ทั้ง GitHub Pages และ Netlify

Netlify: เชื่อมรีโปนี้ได้เลย มี `netlify.toml` สั่ง build ด้วย `npm run build` และเผยแพร่โฟลเดอร์ `dist`

GitHub Pages: ในรีโปให้เปิด Pages จาก GitHub Actions แล้วพุชขึ้นสาขา `main` หรือ `master` เวิร์กโฟลว์ `.github/workflows/pages.yml` จะ build แล้วปล่อยให้เอง
